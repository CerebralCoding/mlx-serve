# Class-guard pins for `zig build lint` (scripts/lint.py, rule pin-unmatched): a source-scan test becomes one line here.
# Format, one pin per line, TAB-separated: <file glob from the repo root> <TAB> <needle> <TAB> <rule it guards>
# A pin passes when at least one file matching the glob contains the needle (a plain substring). `#` lines are comments.
